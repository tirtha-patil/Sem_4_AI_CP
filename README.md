# Space Rover Exploration Agent

This project simulates an intelligent rover agent navigating terrain using AI search algorithms.

## Algorithms Implemented

- Breadth First Search (BFS)
- Depth First Search (DFS)
- A* Search

## Tech Stack

Backend:
Python
FastAPI

Frontend:
React

## Goal

To demonstrate how intelligent agents solve navigation problems using search strategies.
