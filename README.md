# 🚀 Space Rover Exploration Agent

An intelligent rover navigation system that uses Artificial Intelligence search algorithms to explore terrain and find paths to a target destination.

## 📌 Overview

This project demonstrates how intelligent agents solve navigation problems using different search strategies. It explores the differences between uninformed and informed search algorithms through a simulated rover environment.

## ✨ Features

- Autonomous rover navigation and pathfinding.
- Multiple AI search algorithms for route exploration.
- Goal-directed navigation through a terrain environment.
- Backend API integration with an interactive frontend.

## 🧠 Algorithms Implemented

- **Breadth-First Search (BFS):** Explores nodes level by level and finds the shortest path in an unweighted graph.
- **Depth-First Search (DFS):** Explores paths deeply before backtracking.
- **A* Search:** Uses path cost and a heuristic to guide the search toward the goal.

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI
- **Frontend:** React
- **Concepts:** Intelligent Agents, State-Space Search, Pathfinding, Heuristic Search

## ⚙️ Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd Sem_4_AI_CP
```

Install the backend dependencies according to the project configuration. For the frontend, navigate to its directory and run:

```bash
npm install
npm run dev
```

Start the FastAPI backend using the project's configured entry point.
